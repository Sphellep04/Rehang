# Moderator guide

For the founder and the part-time community and moderation lead. The goal is consistent, fast decisions that users can trust.

## Queues and response targets

| Queue | Target | Where |
|---|---|---|
| ID verifications | Within 24 hours (same day during the pilot) | Admin → Verifications |
| Reports (listings, users, messages) | Within 12 hours | Admin → Reports |
| Order problems (Phase 1) and disputes (Phase 2) | Decision within 3 working days | Admin → Disputes |
| Photos-reviewed brand checks | Within 24 hours | Admin → Brand checks |
| Flagged listings (duplicate photos, contact info) | Within 12 hours | Admin → Flags |

**Daily routine (about 30–45 minutes at pilot volume):** verifications → reports → disputes → flags → spot-check 10 random new listings.

## ID verification

Follow the [review checklist](../product/verification-and-limits.md#moderator-review-checklist-about-2-minutes). When in doubt, **escalate, don't guess.** Never download or screenshot ID images.

## Reports: decision table

| Report | Check | Action |
|---|---|---|
| Prohibited item | Compare with the [prohibited list](../policies/prohibited-items.md) | Remove the listing and notify the seller with the reason. Strike if clearly deliberate |
| Stock or stolen photos | Reverse image search, duplicate-photo flag | Remove. Strike |
| Wrong condition or hidden flaws | Photos versus condition definitions | Ask the seller to edit within 24 hours, otherwise remove |
| Asking to move to WhatsApp or pay outside the app | Chat log | Warning the first time, strike after that |
| Deposit or upfront delivery-fee request | Chat log | Strike. Remove the listing |
| Harassment or threats | Chat log | Strike or suspension depending on severity. Threats of violence lead to a ban |
| Counterfeit | Photos, price, seller history | Remove. Strike. Ban for repeat offenders |
| Suspected fraud (fake payment proof, stolen ID) | Order events, verification | Suspend immediately. Escalate to the founder |

Always record a short reason. Users see it.

## Scam signals

Review the account when **two or more** of these appear:
- New account (under 14 days old) listing several items over N$1,000, or designer brands
- Photos found on other accounts or the web
- Asks for WhatsApp, a deposit or a "delivery fee" in the first messages
- Prices far below the usual range for the brand
- Several accounts from the same device or with the same ID hash
- Many cancelled or no-show orders

Actions: hold the listings → ask for extra photos (item with a handwritten note saying "Rehang" and the date) → re-verify → suspend if not satisfied.

## Order problems and disputes

1. Read the listing (the version at the time of the order, from `order_events`), the chat and both statements.
2. Compare the buyer's photos with the listing photos and condition grade.
3. Decide by these rules:
   - Clear mismatch with the listing → the buyer wins (refund, or a strike for the seller in Phase 1).
   - Flaw was shown or described → the seller wins.
   - Not enough evidence → ask each side for more once (24 hours), then decide on what's available.
   - Change of mind → the seller wins.
4. Write a decision note both sides can read: facts, rule applied, outcome.

## Ban ladder

Warning → strike (see the [strike table](../product/orders-meetups-and-delivery.md#strikes)) → 14-day suspension → permanent ban. **Immediate ban** for: fraud, stolen goods, threats of violence, using someone else's ID, repeatedly selling counterfeits.

Users can appeal once by email. The founder reviews appeals within 5 working days.

## Law enforcement requests

- Only the founder handles police requests. Moderators pass them on.
- Ask for the request **in writing**, on official letterhead or from an official email address, with a case number.
- Share only what the request covers and the law requires ⚖️ (confirm the process with the lawyer).
- Record every request in a private log: date, officer, case number, data shared.
- For reports of stolen goods from the public: remove the listing, keep the records, and tell the reporter to open a police case.

## Wellbeing

Moderation can be draining. Take breaks, don't moderate late at night, and escalate anything distressing to the founder.
